# Финляндия 2026 — проект

Общее: тотальная оборона, лесная промышленность, технологии, Арктика и Балтика.

1. **Северная оборона:** НАТО → зимняя армия → Северная лига.
2. **Балтийская интеграция:** порты → энергетика → Балтийская конфедерация с Эстонией, Латвией, Литвой и Польшей.
3. **Арктический курс:** Лапландия, наука, логистика → Арктическое содружество.

Ни один путь не требует территорий России/РФ.
