# Заглушки исторических и региональных флагов

Белые PNG 1280×720 для стран, колоний, империй, исторических государств и регионов стран, чьи периоды пересекаются с 1500 годом. Городские флаги не включены.

Каждому файлу соответствует запись в `historical-flags-catalog.json`: там указаны имя, периоды, тип и ссылка на страницу-источник для поиска и перерисовки.

Реестр сформирован из метаданных [niemela/flags](https://github.com/niemela/flags), распространяемых по CC BY-SA 4.0. Изображения флагов из источника не использовались — в этой папке только созданные белые заглушки.
