# Versailles Hall reference model

`versailles-hall.obj` + `versailles-hall.mtl` — отдельная процедурная модель для визуального согласования сцены.

Модель содержит длинную галерею, светлый мраморный пол, 17 окон, 17 зеркальных панелей, золочёные пилястры, колонны, потолок, семь люстр, центральный стол и ряды кресел.

Открывается в Blender, Windows 3D Viewer, MeshLab и большинстве онлайн OBJ-viewer.

Пересоздать модель после изменений:

```text
node tools/build-versailles-reference.mjs
```
